# FR-9.4, every path it changed is named

| ID | Requirement | |
|---|---|---|
| FR-9.4 | An install **names every path it changed** to the person who ran it. | [A] |

They are the user's files. An installer that writes four locations and reports
success has told them the least useful true thing available.

It is also what makes an uninstall believable: FR-9.13 says everything is
removed, and this is the list a person can check it against without reading the
source.
