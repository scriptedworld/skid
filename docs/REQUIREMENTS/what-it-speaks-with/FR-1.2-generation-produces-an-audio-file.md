# FR-1.2, generation produces an audio file

| ID | Requirement | |
|---|---|---|
| FR-1.2 | Generation produces an **audio file**. Nothing streams to a device from inside skid. | [A] |

A file is what FR-1.3 hands to a player and what FR-4.2 lets skid prepare ahead
of time. Streaming would collapse generation and playback into one operation and
take both properties away.
