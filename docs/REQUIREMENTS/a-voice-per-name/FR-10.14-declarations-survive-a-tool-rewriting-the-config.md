# FR-10.14, declarations survive a tool rewriting the config

| ID | Requirement | |
|---|---|---|
| FR-10.14 | Every declaration in the config is still there, unchanged, after a tool writes the config. | [D] |

Derived from FR-10.10 and FR-7.1. `set_voice` and the substitution tools rewrite
the whole file in wrench's canonical form, so a setting the writer does not
carry through is deleted by a call that has nothing to do with it.
