# FR-10.6, an exhausted list reuses the quietest voice

| ID | Requirement | |
|---|---|---|
| FR-10.6 | When every configured voice is already assigned, a new name is given the voice whose last clip is oldest. Assignment never fails and never falls back to a single default. | [A] |

Chosen first-hand 2026-08-30 from three options. The two set aside are recorded
because the reasons are the useful part.

**Stealing the quietest name's voice** was rejected: a session that goes quiet
for an hour and comes back would sound like somebody else, which breaks exactly
what FR-10.2 is for.

**Falling back to a configured default** was rejected because every overflow
name would then sound alike, and alike to the default. Sharing with one other
name is a smaller collision than sharing with all of them.

**Reuse is a collision this project has already accepted.** Two sessions using
one name share a voice under FR-10.2, so exhaustion reaches the same place by a
different road rather than introducing a new failure.

Exhaustion is reachable rather than theoretical. Fourteen agent sessions were
running on 2026-08-30 against a list of 28.
