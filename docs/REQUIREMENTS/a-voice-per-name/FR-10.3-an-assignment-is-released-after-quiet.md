# FR-10.3, an assignment is released after quiet

| ID | Requirement | |
|---|---|---|
| FR-10.3 | An assignment is released once its name has been quiet for the assignment window, and the voice returns to the pool. | [A] |

Asked for first-hand 2026-08-30, so the shortlist is not exhausted by sessions
that have long since gone.

Names are not closed. A session ends by going away rather than by saying so, and
nothing tells skid which of the names it has seen still exists. Quiet is the
only evidence available, so it is what the release is keyed to.

**A released name is not a forgotten one.** It may speak again and be assigned
again, and there is no promise it gets the voice it had. Holding one in reserve
would defeat the release.

`clank/tasks/skid/voices/10` records the alternative that was considered and set
aside: noticing when a session runs `/clear` and becomes a new id. Bound to the
name that is moot, because a session that clears keeps calling itself the same
thing.
