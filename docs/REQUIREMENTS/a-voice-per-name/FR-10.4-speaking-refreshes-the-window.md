# FR-10.4, speaking refreshes the window

| ID | Requirement | |
|---|---|---|
| FR-10.4 | Speaking restarts a name's assignment window. The window is measured from the last clip spoken for that name, or from when the voice was assigned while there has not been one. | [A] |

Asked for first-hand 2026-08-30: an expiry that refreshes with usage, so an
assignment is held while a session keeps talking.

Without the refresh the window would be a lease on the assignment rather than a
measure of absence, and a session talking steadily for seven hours would lose
its voice mid-conversation. That is the failure this row exists to name.

**Measured from the end of speech**, which is FR-7.4's rule for the quiet
window, for the same reason: what a listener experienced is when the clip
finished, not when it was queued. The two windows are independent and answer
different questions, so sharing the measurement point is a coincidence worth
stating rather than a shared mechanism.
