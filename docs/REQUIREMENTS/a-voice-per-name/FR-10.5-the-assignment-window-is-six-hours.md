# FR-10.5, the assignment window is six hours

| ID | Requirement | |
|---|---|---|
| FR-10.5 | The window in FR-10.3 and FR-10.4 is **six hours**, and it is configurable. | [A] |

Asked for first-hand 2026-08-30, as the figure alongside the request.

Six hours is long, and deliberately so. It is a bet about how long a quiet
session is still a session, and being wrong in one direction costs a name its
voice while it is still working, where being wrong in the other costs a voice
sitting unavailable. The first is audible and the second is not.

**It is a PREFERENCE, not a measurement.** Nothing about the machine sets it and
nothing measured produced it. Change it if the shortlist starts running out
before assignments release.

Configurable for the reason FR-3.4 gives for the quiet window: the right number
depends on how the estate is used, and a value in a file can be argued with
where a constant cannot.
