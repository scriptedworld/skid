# FR-10.8, each voice carries a unique alias

| ID | Requirement | |
|---|---|---|
| FR-10.8 | Every configured voice carries an alias, and no two in the list share one. | [A] |

Asked for first-hand 2026-08-30: a name for each voice that maps to the
underlying kokoro voice id.

kokoro ids are not meant to be said to a person. Two on the shortlist collide by
ear, `af_sarah` and `if_sara`, and two share a stem, `af_bella` and
`bf_isabella`. An alias means a person can say *make silo Wayne* rather than
*make silo im_nicola*.

**An alias is read and never spoken.** skid announces the name of the calling
agent under FR-3.2 and never the alias, so no alias reaches a speaker. The bar
it has to clear is a person telling two rows apart in a config file.

**Uniqueness is what makes it an identifier rather than a comment.** Two rows
claiming one alias would make the name ambiguous exactly where something reads
it, and nothing about the second row would look wrong.

Distinctness *by ear* is a real problem and it is not this one. It belongs to
the names callers pass to `speak`, which are chosen wherever sessions are named
and are outside skid.
