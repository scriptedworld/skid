# FR-10.12, a declared voice is kept from the pool

| ID | Requirement | |
|---|---|---|
| FR-10.12 | A voice declared for one name is not assigned to an undeclared name while the shortlist holds a voice that nobody declared and no name holds. | [D] |

Derived from FR-10.10. A declared voice is how a listener knows that agent, so
another name arriving in it would be heard as that agent.

The row stops where the free voices run out. What happens then is FR-10.16, and
it is open.

Two declarations may name the same entry. That is a choice made in the file,
and skid does not second-guess it.
