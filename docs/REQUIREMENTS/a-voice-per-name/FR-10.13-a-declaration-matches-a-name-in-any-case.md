# FR-10.13, a declaration matches a name in any case

| ID | Requirement | |
|---|---|---|
| FR-10.13 | A declaration applies to a submitted name that differs from it only in letter case. Two declarations that differ only in letter case are refused when the config is read, naming both. | [D] |

Derived from FR-10.10. Agents send their names in whatever case their own brief
spells them: `status` showed `ramona` on 2026-10-05, and the team charter writes
`Ramona`. A declaration written one way and a call made the other would fall
through to the pool, which is the silent failure FR-10.11 refuses for a wrong
alias.

The comparison is Python's `str.casefold`. Two declarations that fold to one
name would make which applies depend on file order, so they are refused instead.

FR-3.1's announced name and FR-10.2's assignment key are untouched: they keep
the name exactly as sent.
