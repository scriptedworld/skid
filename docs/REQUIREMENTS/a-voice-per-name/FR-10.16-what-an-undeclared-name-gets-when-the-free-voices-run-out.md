# FR-10.16, what an undeclared name gets when the free voices run out

| ID | Requirement | |
|---|---|---|
| FR-10.16 | Which voice an undeclared name is given when every voice nobody declared is already held. | [?] |

Open. I was asked on 2026-10-05 and the answer was that the team is not large
enough to have run out of voices yet, and what should happen then is undecided.

Until it is decided, FR-10.6 applies unchanged and nothing was built for this
case. Recorded here because of what FR-10.6 does in it: it reuses the voice
silent longest by the assignment table, and a declared voice is not in that
table, so it reads as never heard and is the first one reused. An undeclared
name then speaks in an agent's declared voice.
