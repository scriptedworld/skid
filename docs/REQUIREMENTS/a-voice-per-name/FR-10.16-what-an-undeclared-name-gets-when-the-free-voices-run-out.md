# FR-10.16, running out of voices is announced

| ID | Requirement | |
|---|---|---|
| FR-10.16 | A name given a voice by FR-10.6's reuse, because no voice was free for it, is greeted with `We've run out of voices.` after its introduction, for as long as it holds that voice. A name holding a voice of its own, or a declared one, is not. | [A] |

I asked for it: when the voices run out, the greeting says so. A shared voice
otherwise makes two names sound like one with nothing to say why.

The voice itself is still FR-10.6's, the one silent longest, and nothing was
changed about which. A declared voice has no entry in the assignment table, so
it reads as never heard and is the first one reused. Growing the pool is the
answer I chose over a fallback voice: no blends, because they make everybody
harder to tell apart.
