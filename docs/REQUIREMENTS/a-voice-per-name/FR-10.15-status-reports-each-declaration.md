# FR-10.15, status reports each declaration

| ID | Requirement | |
|---|---|---|
| FR-10.15 | `status` reports every declaration in force, as the name the config declares and the alias of its voice. | [D] |

Derived from FR-10.10. `assigned` reports the pool and a declared name is not in
it, so without this a caller asking which voice an agent speaks in is told
nothing for exactly the agents that were given one on purpose. Reported as
`declared`, beside `assigned`, so the two sources stay distinguishable.
