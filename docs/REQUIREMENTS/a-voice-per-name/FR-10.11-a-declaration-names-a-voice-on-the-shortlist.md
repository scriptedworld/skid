# FR-10.11, a declaration names a voice on the shortlist

| ID | Requirement | |
|---|---|---|
| FR-10.11 | A declaration names an entry on the `voices` shortlist by its alias. A declaration naming no entry is refused when the config is read, and the refusal names the declared name and the alias. | [D] |

Derived from FR-10.10 and FR-10.1. The shortlist is the statement of what
renders on this machine, so a declared voice is one of its entries and not just
any kokoro id.

By alias and not by voice id, for three reasons. The alias is unique,
FR-10.8, where two entries may share a voice id with different pipelines. The
entry carries its pipeline, FR-10.7, so naming it brings the pronunciation that
was chosen with it. And the alias is what `status` already reports, so a person
reads the same word in the file and in the answer.

Refused rather than ignored, for the reason an unknown config key is: a
declaration that silently fell through to the pool would put the agent in a
voice nobody chose, and nothing about the file would look wrong.
