# FR-8.2, a substitution is heard, not read

| ID | Requirement | |
|---|---|---|
| FR-8.2 | The purpose is pronunciation: a word kokoro says wrongly is replaced by something that sounds right. The substitution is **heard, not read**, so it need not be a real spelling. | [A] |

Nothing validates a replacement as a word. `kokoro` becoming `koh koh roh` is
the intended use, and a spell check over the substitution set would reject
exactly the entries that work.
