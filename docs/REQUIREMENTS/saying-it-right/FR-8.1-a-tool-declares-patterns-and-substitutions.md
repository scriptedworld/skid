# FR-8.1, a tool declares patterns and substitutions

| ID | Requirement | |
|---|---|---|
| FR-8.1 | An **MCP tool declares patterns and their substitutions**, applied to the text before it is spoken. | [A] |

An entry declares whether its pattern is a literal or a regular expression
(FR-7.7). The set is global (FR-7.9) and it persists to the config file
(FR-7.8), in file order (FR-8.4), applied in one pass (FR-8.5).
