# FR-8.1, a tool declares patterns and substitutions

| ID | Requirement | |
|---|---|---|
| FR-8.1 | An **MCP tool declares patterns and their substitutions**, applied to the text before it is spoken. | [A] |

Whether a pattern is a literal or a regular expression is FR-7.7, whether the
set is global or per name is FR-7.9, and whether it survives the process is
FR-7.8.
