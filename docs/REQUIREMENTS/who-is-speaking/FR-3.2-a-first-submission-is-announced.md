# FR-3.2, a first submission is announced

| ID | Requirement | |
|---|---|---|
| FR-3.2 | If a name's submission is the **first within `x` seconds** for that name, the spoken output is prefixed `Hi, [name] here.` | [A] |

The window is per name, so one agent talking continuously does not suppress
another agent's announcement.

`x` is FR-3.4 and its value is FR-7.4.
